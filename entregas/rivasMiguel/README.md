# Reto 002 — Análisis y Corrección de Modelos UML (`pyTetris`)

Este repositorio recoge la revisión y corrección de los modelos UML del proyecto [`pyTetris`](https://github.com/puntoReflex/pyTetris), identificando incoherencias entre artefactos, inconsistencias internas y decisiones de modelado discutibles desde el modelo del dominio hasta los diagramas de contexto y el detalle de los casos de uso.

## Contenido del repositorio

- **[`Analisis.md`](./docs/Analisis.md):** Resumen global de hallazgos e índice de todas las correcciones.
- **[`correcciones/`](./docs/correcciones/):** Fichas detalladas con la justificación y comparativa visual de cada artefacto corregido.
- **[`modelosUML/`](./modelosUML/):** Código fuente PlantUML (`.puml`) de los diagramas corregidos.
- **[`images/`](./images/):** Diagramas renderizados en formato `.svg` a partir de los modelos corregidos.
