# Modelo de Dominio

## Glosario

* **Persona:** Individuo que puede realizar acciones para conseguir aura.
* **Acción:** Comportamiento realizado por una persona.
* **Contexto:** Situación en la que se realiza una acción.
* **Aura:** Medida intangible de presencia o reconocimiento social.
* **Farmear:** Realizar acciones con el objetivo de conseguir aura.

## Suposiciones

* Una persona puede realizar diferentes acciones para conseguir aura.
* El contexto puede influir en la cantidad de aura obtenida.
* Las acciones pueden realizarse intencionadamente para conseguir aura.
* Una persona puede acumular aura mediante diferentes acciones.

## Decisiones de modelado

Se ha separado la acción del contexto porque una misma acción puede producir diferentes resultados dependiendo de la situación en la que se realice.

El aura se ha modelado como un concepto independiente porque representa el resultado que se obtiene al realizar determinadas acciones.
