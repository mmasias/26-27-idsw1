
# Modelo del dominio: Farmear aura

## Glosario

- **Persona:** individuo que realiza acciones para mejorar su imagen.
- **Accion:** comportamiento que puede influir en el aura de una persona.
- **Aura:** imagen de confianza o prestigio que alguien transmite.
- **Observador:** persona que presencia y juzga una acción.
- **Valoracion:** opinión positiva, negativa o neutra sobre una acción.
- **Contexto:** situación en la que se realiza una acción.

## Supuestos

- Una persona puede realizar varias acciones para aumentar su aura.
- Cada acción ocurre en un contexto determinado.
- Una misma acción puede recibir diferentes valoraciones.
- Un observador puede valorar distintas acciones.
- El aura puede aumentar o disminuir según las valoraciones recibidas.

## Decisiones de modelado

El **Aura** se representa como la imagen que proyecta una **Persona**, y se relaciona con las **Valoraciones** porque depende de cómo los **Observadores** interpretan sus acciones.
